## 约定

1. **批次**用一级标题（`# 批次 X：...`），**一次提交**用二级标题（`## X1：...`）
2. 提交前，从对应批次文档复制内容作为 commit message
3. **不变量**（协议事实 / 架构决议 / 实测发现 / 重大问题存档）只写在 `FACTS.md`
4. **消灭进度表**在 `batch-B.md` 顶部维护，粒度 = **顶层 type + 子类型**
   （例：`message_update › thinking_delta`，不能只写 `message_update`）
5. 测试用 mock LLM（`scripts/mock-server.mjs`），不依赖真模型

### ② ★ 模型下拉的排序（用户定的 ✓）

用户原话 ✓：
> "按供应商排序，然后供应商相同的放到一起，
>  然后供应商之间怎么排的？按数量排，少的放前面，多的放后面。"

**实现** ✓：
```typescript
function sortCatalog(list) {
    const byProv = new Map<string, Item[]>();
    for (const m of list) { (byProv.get(m.provider) ?? byProv.set(m.provider, []).get(m.provider)).push(m); }
    return [...byProv.entries()]
        .sort((a, b) => a[1].length - b[1].length || a[0].localeCompare(b[0]))
        //               ↑ 组内模型数量：少的在前 ✓        ↑ 数量相同按名字（顺序稳定 ✓）
        .flatMap(([, arr]) => arr.sort((x, y) => x.id.localeCompare(y.id)));
}
```

**实测结果** ✓（用户环境的真实数据 ✓）：
```

【deepseek】(3 个)        deepseek-v4-flash · deepseek-flash · deepseek-v4-pro

【github-copilot】(34 个) claude-fable-5 · …
                          ↑ 34 个沉到最底 ✓ 不挡路 ✓
```

## 第二部分：★ 面板互斥（用户发现的 ✓）

用户原话 ✓：
> "一块板子开着的情况下，点另一个应该把原来那块板子收回去，并且打开新板子才对吧？"

**新增 `src/webview/panels.ts`** ✓：
```typescript
const closers = new Map<string, () => void>();
let active: string | null = null;

export function registerPanel(id, close) { closers.set(id, close); }

export function activatePanel(id) {           // ★ 声明"我要打开了"
    if (active && active !== id) closers.get(active)?.();   // 自动收起前一块 ✓
    active = id;
}
export function deactivatePanel(id) { if (active === id) active = null; }
```

**四块面板各自注册** ✓：
```
sessions（会话）· notices（通知）· settings（设置）· skills（技能）
→ 打开任何一块 → ★ 自动收起其他 ✓
```

**★ 为什么不用"互相调用"** ✗：
```
会形成循环依赖 ✗（session ↔ settings ↔ skills …）
而且每加一块板子就要改所有板子 ✓
→ 注册表模式：加新面板只需注册一次 ✓
```

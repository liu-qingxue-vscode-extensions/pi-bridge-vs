## 一、★ 斜杠命令补全（新功能）

### ① 用户要的

```
“按下斜杠就应该列出所有命令 ✗ 随着输入内容逐渐收敛 ✓
 上下键可以在里面自由切换 ✗ 自动选中第一项没有问题 ✓”
```

### ② 数据源：RPC 的 `get_commands`

```
{"type":"get_commands"}
→ { commands: [{ name, description?, source, sourceInfo }] }
  source: "extension"（pi.registerCommand ✓）
        | "prompt"  （模板 .md ✓）
        | "skill"   （技能 ✗ 名字前缀 skill: ✓）

★ 文档明说（rpc-commands.md:834）：
  "Built-in TUI commands (/settings, /hotkeys, etc.) are not included.
   They are handled only in interactive mode and 【would not execute
   if sent via prompt】."
```

### ③ ★ 决定：内置命令【不加】

```
用户起初说“原生命令呢被你过滤掉了？你别过滤啊！刚迁移过来的人都可以用的”
★★ 但查完文档后 ✗ 他自己结论：“内置秘密没用是吧？行吧，那就不加呗”✓
理由：RPC 下发了也不执行 ✗（会被当普通消息 ✓）加了反而误导 ✓
★ 而且它们大多数我们【有按钮替代】✗：
  /model → 模型选择器 · /compact → 压缩按钮 · /new → 新建会话
  /name → 会话名按钮 · /fork·/clone → 气泡上的刀 · /export → 会话面板
  /copy → 气泡上的复制 · /settings → 设置面板 · /reload → 重载按钮
```

### ④ 实现（`src/webview/slash-menu.ts`）

```
触发：内容以 / 开头 + 光标在第一行 + 前缀里没有空格 ✓
过滤：前缀命中优先 ✗ 子串命中次之 ✓（好找 ✓）
交互：↑↓ 移动 · Enter/Tab 填入（★ 只填不发 ✓）· Esc 关闭 ✓
缓存：首次 setup 就主动拉一次 ✗ 之后复用 ✓
```

## 二、★ 交互面板的最后一串修正

### ⑤ ★★ focus 监听里调 redraw → Enter 被吞（元凶 ✗）

```
用户报：“enter 没用了 ✗ enter 驱动的按钮点击也没用 ✗
        必须去点那个去确认”✓

根因：ta.addEventListener("focus", () => { ...; h.redraw(); })
   → 光标一进输入框就【整个 DOM 重建】✗
   → textarea 被换成新的 ✓
   → 用户按 Enter 时若正好碰上重建 ✗ 事件就丢了 ✓

修：只清 .kbd 高亮 ✗ DOM 一动不动 ✓
★ 教训：focus / input 这类高频事件里【绝不能全量重绘】✗
```

### ⑥ ★ 答卷最后一题答完 → 自动去确认页

```
旧：advanceToNextUnanswered() 找不到未答题就【不动】✗
   → 用户还得手动点“去确认”✓
新：找不到就 state.page = confirmPage() ✗ 直接给确认页 ✓
```

### ⑦ ★ 确认页 Enter = 提交全部

```
用户：“提交页面的提交全部应该吃一下 enter”✓
★ 加在 document keydown 里 ✗ 只有【全部答完】才真的提交 ✓
  （否则什么都不做 ✓ 不会误提交 ✓）
```

### ⑧ ★ 斜杠列表被截断到 12 条

```
用户：“你这数目有点太少了 ✗ 下面明明有东西 ✗ 但前端就是不给 ✗
      缺少一个滑块 ✗ 到最下面的时候会弹到第一个去”✓

根因：① matches.slice(0, 12) 只渲染 12 条 ✗
      ② ↑↓ 用了 Math.min(matches.length, 12) ✗ → 12 条内循环 ✓
修：显示全部 ✗ 靠 CSS max-height: 260px + 细滚动条限高 ✓
    ↑↓ 在【全部】里循环 ✓ + selected 自动 scrollIntoView ✓
```

### ⑨ ★ keyup 把选中重置（长按才能选下面 ✗）

```
用户：“上下怎么被锁定到第一个项目了？往下我得长按下键才能选中 ✗
      手一松又弹回去了”✓

根因：keydown 里 selected++ ✗ 紧接着 keyup 又调 refreshSlashMenu()
   → 又把 selected 重置为 0（“自动选中第一项”✓）
修：Arrow ↑↓ 的 keyup 【不刷新】✗ 只有 ←→ 才刷新（且保留选中 ✓）
```

### ⑩ ★ 菜单改变输入区高度 → 消息区被盖

```
用户：“UI 遮挡 ✗ 无法把上面的气泡往上滑”✓
修：菜单每次重绘后 rAF 里调 syncPadding() ✓（消息区留白跟上 ✓）
```

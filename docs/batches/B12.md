```

   → 因为那两条路走的不一样 ✗（一个是监听 + 重推，一个是没监听 ✗）

3. 内存：缓冲 500 条原始 JSON → 开发结束应能彻底关掉 ✓
```

### ② ★ 架构修正：折叠从「入库时」移到「出口」

**这是本轮的根因修复** ✓

```
旧：log() 命中黑名单 → 【存成折叠载荷】（只有 type + count，详情丢掉 ✗）
    → 改黑名单时，历史数据的详情【早就没了】→ 无法"重新显示" ✗
    → 用户的感受就是"黑名单不实时响应" ✓

新：缓冲【永远存完整数据】✓
    折叠发生在【出口】（发前端之前）✓
    → 改规则 → replayHistory() 重新算折叠 → 立即生效 ✓
```

**配套**：
```ts
// 监听设置变化 → 重算折叠 + 重放（和 styleVars 同一套路 ✓）
vscode.workspace.onDidChangeConfiguration((e) => {
    if (e.affectsConfiguration("pi-bridge.debug")) {
        if (!this.isEnabled()) this.buffer.clear(); // 关总开关 → 清空 ✓
        this.replayHistory();
    }
});
```

> ★ 重放协议新增 `debug-clear`（先清前端再重推）✓
> ★ **为什么是"清空重推"而不是"增量补"**：折叠/过滤是**有状态的**
>   （规则变了，之前推过的可能要撤回）✗ → 全量重推最不会错 ✓（数据量小，成本可忽略 ✓）

### ③ 总开关 `pi-bridge.debug.enabled`

```
默认 true。关掉后：
  · log() 直接 return ✓（缓冲不涨、不推前端）
  · 缓冲立即清空 ✓（用户要求："哪怕有数据包过来也不再接收，也是空空的"✓）
```
用途：开发结束 / 收工 → 关掉省内存 ✓

### ④ ★ 折叠规则语法（三轮讨论才定稿）

**用户的核心目的（第一性原理）**：
> "我的核心目的只有一个：**精确忽略我想要忽略的那一部分数据包**。
> 这部分在我添加之后就忽略了，而没有添加的部分继续保留。"

**所以是【两个锚点】** ✓：
```
锚点1：type              —— 锁定事件类型（必填）
锚点2：字段路径[=值]      —— 在类型内部再精确到子集（可选）
两个都满足才忽略 ✓   不满足的 → 完整显示 ✓
```

**最终语法**（字符串数组 → 能在 VS Code 设置界面编辑 ✓）：
```jsonc
"pi-bridge.debug.collapse": [
  "turn_start",                                            // 锚点1：整个 type
  "message_update:assistantMessageEvent.type=text_delta",  // 锚点1 + 锚点2
  "tool_execution_start:toolName"                          // 锚点2 不带 =值 → 取到就忽略
]
```
```
· 冒号前 = type（type 里不会有冒号 → 切分无歧义 ✓）
· 冒号后 = 点号字段路径（任意深度 ✓ —— 路径本身就是嵌套，不需要"数组套数组"✗）
· 再带 =值 → 还必须相等才命中 ✓
· 取不到值 → 不命中（宁可多显示，也不要出一坨 ? ✗）
```

**★ 记录一下走过的弯路**（避免以后重复讨论 ✗）：
```
弯路一：设计成 "type.路径"（点号分隔）✗
        → type 里没点，理论可行，但【人和机器都容易读错分界】
        → 改成冒号 ✓

弯路二：设计成 "by 字段"（纯分组语义）✗
        → by 会把【所有值】都各折一段（text_delta 折、thinking_delta 也折）
        → 但用户要的是"**只折我指定的那一个**，其余完整显示" ✓
        → 所以必须带 =值 ✓

弯路三：删掉了 hiddenTypes（以为它被取代了）✗
        → 用户指出：它其实是【这套语法的子集】（只有锚点1）✓
        → 最后确实合并成一个配置，但那是"用字符串同时表达两种"✓
          而不是"新的取代旧的"✗
```

**命中后的表现**（保住时序 ✓）：
```
折叠【不会让数据消失】，而是变成一行：
  message_update › type=text_delta    ×300   （已忽略，仅计数）
```

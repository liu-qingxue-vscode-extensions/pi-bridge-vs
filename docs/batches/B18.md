## B18

### ① ★ 气泡 wrapper 重构（为复制按钮铺路）

**用户提的架构问题** ✓：
> "从架构来讲，它是它的一部分比较好，还是两个气泡拼一下？还是某种子气泡，你来决定吧"

**决定：wrapper + 内层** ✓
```html
<div class="bubble-wrap text">          ← 管【布局】：宽度 / 对齐 / 间距
  <div class="bubble text">…内容…</div>  ← 管【视觉】：背景 / 边框 / 圆角 / padding
  <div class="bubble-actions">          ← 悬浮动作区（width:100% → 跟随气泡宽度 ✓）
    <button>复制</button>
  </div>
</div>
```

**为什么不是另外两种方案** ✗：
```
· 塞进 .bubble 里 → 会被气泡的背景/边框包住 ✗ 视觉不对 ✓
· 当成另一个气泡 → 语义不清（它不是一条消息 ✗）
```

**牵扯到的改动**（一定要记 ✗ 容易漏 ✓）：
```
★ 所有【间距 / 对齐】规则都要从 .bubble 改到 .bubble-wrap ✗
  （因为 wrapper 现在才是 #messages 的直接子项 ✓）
· .bubble + .bubble           → .bubble-wrap + .bubble-wrap ✓
· .bubble.user → align-self   → .bubble-wrap.user ✓
· 那一堆 gapXXXToYYY 的组合选择器 → 全部改 ✓
· 居中模式的规则也要改 ✗（见 ⑦ —— 我就在这里漏了一处 ✓）
```

### ⑥ 工具气泡的滚动（结果标题固定 + 参数各自滚动）

**用户发现的问题** ✓：
> "工具气泡内容比较多的时候，它会有一个滑块儿……
>  但 result 也作为滑块的内容被滑上去了，它应该固定住 ✓"

**问题根源**：`.tool-result` 有 `max-height: 220px; overflow-y: auto` ✗
→ 整个结果区一起滚 → **标题行被滑走** ✗

**修** ✓：
```css
.result-toggle {
  position: sticky; top: 0; z-index: 1;
  background: var(--pi-bg-tool-result, …);   /* ★ 必须不透明 ✗ 否则文字穿透 ✓ */
}

/* ★ 每个参数【值】自己限高滚动（用户要求 ✓）
   —— 参数名在同一行左侧 → 天然固定 ✓ 不会被滑走 ✓ */
.arg-val { max-height: var(--pi-tool-arg-max, 180px); overflow-y: auto; }
```

**两个开关 + 两个限高值**（都可配 ✓）：
```jsonc
"pi-bridge.style.toolArgsScroll": true      // 关 = 参数全部展开 ✓
"pi-bridge.style.toolResultScroll": true    // 关 = 结果全部展开 ✓
"pi-bridge.style.toolArgMaxHeight": 180
"pi-bridge.style.toolResultMaxHeight": 220
```
> 用户："要不加个配置项……我怎么感觉全部展开反而更好，反正我屏幕大"✓
> 实现：布尔用 CSS 类（`:root.no-arg-scroll` ✓ CSS 没有布尔变量 ✗）

### ⑧ ★ 修 bug：居中模式不对齐（用户实测报的 ✓）

**现象**：开着 `centerColumn` 时，用户气泡右端和 AI 气泡右端没对齐 ✗

**根因**（我 wrapper 重构时漏改 ✗）：
```css
:root.centered .bubble { width: 100%; }    ← ★ 改的是内层 ✗
                                            但 wrapper 现在才是布局元素 ✓
                                            → 这条等于没效果 ✓
→ 结果：wrapper 仍 88% ✗ 而 #messages 的 padding 已经是 6% ✓
  → 内容列只剩 "88% 的 88%" ≈ 77% ✗
```
**修**：`:root.centered .bubble-wrap { width: 100%; }` ✓

**居中模式的原理（用户澄清的 ✓）**：
```
用 padding 划出一个【居中区域】（左右两条竖线 ✓）
区域宽度 = bubbleWidth ✓
  · AI 气泡占满区域 → 右端落在右边竖线 ✓
  · 用户气泡右对齐 → 右端也落在同一条竖线 ✓
  · 用户气泡左端【没人管】✓ 可以比左边竖线更靠右 ✓（可以配 maxWidth 控制 ✓）
```

### ⑨ ★ 修 bug：居中模式把 userMaxWidth 覆盖成 100%

```css
:root.centered .bubble-wrap.user { max-width: 100%; }   ← ★ 写死 ✗
→ 用户在居中模式下改 userMaxWidth【完全没反应】✗（重载也没用 ✓）
修：max-width: var(--pi-user-max-width, 88%) ✓
```

> ★ **教训**：`:root.centered` 那组规则里**写死的值**容易悄悄盖掉配置 ✗
> 以后加这种"模式覆盖"时，值也要**走变量** ✓
